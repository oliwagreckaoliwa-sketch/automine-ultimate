# AutoMiner Ultimate

Client-side Fabric mod for Minecraft Java 1.21.11.

## Features
- Automatic mining for selected blocks
- Block whitelist and target selection
- Automatic inventory deposit into a selected chest
- Mining statistics and resource counters
- Configurable HUD and in-game screens
- Configurable keybindings

## Requirements
- Minecraft Java 1.21.11
- Java 21
- Fabric Loader and Fabric API

## Build
Run `gradle build` with JDK 21. The distributable JAR is created in `build/libs/`.

## Controls
Open **Options → Controls → AutoMiner Ultimate** to view or change keybindings.
